Insectra — Pest Control WordPress Theme

Documentation v1.0 — May 2026

1. Introduction

Thank you for purchasing Insectra. Insectra is a modern Pest Control & Disinfection WordPress theme with predefined web elements that helps you build a professional pest control website in minutes.

If you have questions please contact us at help.kodesolution@gmail.com.

2. Requirements

  • PHP 8.0 or greater
  • MySQL 5.6+ or MariaDB 10.0+
  • WordPress 6.0+

4. WordPress Installation

If you don't yet have WordPress installed, follow the official guide at WordPress.org.

5. Theme Installation

5.1. Via Admin Panel

  1. Log in to your WordPress admin area.
  2. Go to Appearance → Themes → Add New → Upload Theme.
  3. Choose insectra.zip, click Install Now.
  4. Click Activate.

5.2. Via cPanel

  1. Open cPanel → File Manager → public_html/wp-content/themes/
  2. Click Upload → choose insectra.zip → Extract.
  3. Activate from Appearance → Themes.

5.3. Via FTP

  1. Unzip insectra.zip on your computer.
  2. Upload the insectra-theme folder to /wp-content/themes/.
  3. Activate from Appearance → Themes.

6. Plugin Installation

The following plugins are recommended:

  • Elementor — page builder (required for full editing)
  • Elementor Pro — Theme Builder header/footer overrides
  • Contact Form 7 — production contact forms
  • WooCommerce — for shop functionality
  • Polylang or WPML — multilingual
  • Loco Translate — translate strings inside the dashboard
An admin notice in WP Dashboard will list any missing recommended plugins with one-click install links.

7. Importing Demo Contents

The theme works out-of-the-box without demo data: front-page.php ships with prebuilt sections that auto-populate using sample data when you have no content yet.

To import full demo content using One Click Demo Import:

  1. Install plugin One Click Demo Import.
  2. Go to Appearance → Import Demo Data.
  3. Click Import Demo Data → confirm.

8. Basic Theme Setting

8.1 Homepage Setting

  1. Go to Pages → Add New → name it "Home" → publish.
  2. Optionally choose a Page Template (Default for prebuilt sections, or Home Layout 2 for the alternate dark hero).
  3. Go to Settings → Reading → Your homepage displays → A static page → Homepage: Home.
If you build the Home page with Elementor, the theme automatically defers to your Elementor layout — no code needed.

8.2 Menu Setting

Go to Appearance → Menus. Create a new menu, add items, then assign it to the location: Primary Menu, Footer Menu, or Mobile Menu.

8.3 Contact Form Settings

Install Contact Form 7. Go to Contact → Add New, copy the shortcode, and paste it into a page or Elementor widget. The theme's default contact section in template-parts/sections/contact.php uses a built-in lightweight form by default.

8.4 Widget Settings

Go to Appearance → Widgets. The theme registers 5 widget areas:

  • Blog Sidebar
  • Footer Column 1, 2, 3, 4

9. Header Setup

Customize header globally in Appearance → Customize → Insectra: Header CTA and Insectra: Brand Colors.

For a fully custom header (with Elementor Pro): Templates → Theme Builder → Add New → Header → assign condition.

10. Footer Setup

Edit footer text from Appearance → Customize → Insectra: Footer. Footer columns are powered by widgets at Appearance → Widgets → Footer Column 1-4.

11. Page Title

Page title banner is controlled from Theme Options → General → Page Title Style (Default / Minimal / Hidden).

12. Custom Post Types

The theme registers 4 main CPTs:

CPTSlugWhere
Services ins_service Dashboard → Services
Staff ins_staff Dashboard → Staff
Projects ins_project Dashboard → Projects
Testimonials ins_testimonial Dashboard → Testimonials

Each post supports Elementor editing — open any item and click "Edit with Elementor".

13. Theme Options

Go to Theme Options in the admin sidebar for global settings (preloader, sticky header, footer layout, copyright, MailChimp action URL, GTM ID, reCAPTCHA key).

Visual content (colors, hero, contact info, footer text, social links, map embed) is in Appearance → Customize under sections beginning with Insectra:.

14. Elementor Widget

Every page, post and CPT entry can be edited with Elementor. The theme exposes the following Elementor Theme Builder locations (Pro):

  • header
  • footer
  • archive
  • single
  • before_content
  • after_content

15. Child Theme

Always make code customizations through the child theme so updates to Insectra don't overwrite your changes.

  1. Upload insectra-child.zip via Appearance → Themes → Add New → Upload Theme.
  2. Activate Insectra Child.
  3. Add your custom CSS to insectra-child/style.css and PHP to insectra-child/functions.php.

16. Multilingual & RTL

The theme is fully translation-ready and ships with:

  • languages/insectra.pot — POT template
  • languages/ar.po — Arabic translation
  • rtl.css — auto-loaded for RTL locales

For Arabic site:

  1. Compile ar.po to ar.mo using msgfmt or Loco Translate.
  2. Settings → General → Site Language → العربية.

For dual-language site, install Polylang or WPML — the topbar language switcher renders automatically.
